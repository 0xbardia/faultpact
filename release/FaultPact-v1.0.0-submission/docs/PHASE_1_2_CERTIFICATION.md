## Final Application Architecture

The contract is the financial source of truth. PostgreSQL stores indexed state,
operational monitoring data, transaction state, and immutable evidence bytes.
The indexer reads counters and entity views, refreshes mutable views, and
reconciles contract state over cached state. Fastify serves bounded read APIs.
Regional workers probe trusted internal targets, aggregate deterministic metrics,
create operational incident candidates, and can produce canonical evidence
artifacts.

No backend path signs ordinary user actions, calculates final claim eligibility,
decides payout amounts, or auto-withdraws claimable credit.

## Backend API

Public read families under `/api/v1` cover network/config/status, providers,
services, pacts, capacities, coverages, incidents, evidence, resolutions,
challenges, and claims. `/api/v1/health`, `/api/v1/ready`, and
`/api/v1/status` expose operational state. `/api/docs` is generated by
Fastify Swagger. Pagination is bounded to 100 rows and query text is bounded.

The internal monitor-target route is disabled without `ADMIN_API_TOKEN` and
requires bearer authentication when enabled. It applies SSRF validation before
persisting a target. The artifact endpoint serves stored bytes directly at
`/evidence/:sha256` and `/api/v1/evidence-artifacts/:sha256/raw`.

## Monitoring Engine

The worker runs region-aware baseline RPC probes for `eth_chainId`,
`eth_blockNumber`, and `eth_getBlockByNumber`. It validates JSON-RPC version,
response ID, result shape, chain ID, block quantities, timeouts, HTTP 429,
non-2xx, malformed JSON, JSON-RPC errors, stale heads, and unknown references.

Availability and error PPM use integer floor arithmetic. p50/p95 use
nearest-rank over monotonic request durations. Block lag is unknown when no
trustworthy reference head exists. Five-minute aggregates retain their probe ID
inputs. Raw samples use `PROBE_RAW_RETENTION_SECONDS` (seven-day default);
immutable artifacts are not pruned.

## Incident Candidate Engine

Candidate states are operational only: `HEALTHY`, `SUSPECTED`, `ACTIVE`,
`RECOVERING`, `CLOSED`, and `EVIDENCE_READY`. Persistence requires three
consecutive failure signals and two recovery signals in the initial worker
policy. Pact thresholds can create an offchain signal; the contract remains
authoritative for final Incident facts and Claims.

## Evidence Pipeline

Evidence uses the final structured `faultpact-probe-v1` shape. Canonical bytes
are UTF-8 JSON with recursively sorted keys, stable integer metrics, and no
insignificant whitespace. SHA-256 is computed over exactly those bytes and
self-checked before storage. PostgreSQL stores the exact `bytea` content under
a unique hash. Existing bytes are compared byte-for-byte, so a collision or
mutation fails.

The runtime smoke stored immutable artifacts, including a 336-byte latest
artifact with SHA
`a280ef65173c6297c3d994b3fb528aa435766b981b58e0e698dfa0cf8f1b90b8`.
Fetching it through the production build API returned HTTP 200,
`application/json`, immutable cache headers, and bytes hashing to the same SHA.

## Reporter Integration

Without `REPORTER_PRIVATE_KEY`, the worker performs an explicit
`MONITOR_ONLY` preflight and does not submit. A configured key is converted to
an address in memory and checked against `is_authorized_reporter` before an
authorized mode can be reported. The key is never persisted or logged.

The submission gate is retry-safe: it checks authorization and existing onchain
presence before sending, so a process timeout does not blindly duplicate an
evidence submission. `AUTO_ONCHAIN_SUBMISSION` is fail-closed because the
current frozen deployment requires a legacy transport shape that has not been
verified for signed writes.

Live reporter write: **NOT RUN — REPORTER_PRIVATE_KEY was not available**.
No state-changing Studio transaction was issued during this implementation.

## Security

SSRF protection rejects loopback, private, link-local, metadata, multicast,
IPv4-mapped special IPv6, credentials, unsupported protocols, disallowed ports,
and redirects. Resolved addresses are pinned for the request. Body, response,
request-time, and pagination limits are explicit.

The API has no user-key custody path. Reporter keys and admin tokens are
environment-only. Prisma parameterization is used; no raw SQL was added other
than the fixed health `SELECT 1`. Evidence is content-addressed and served
without reserialization. The monitor fails closed rather than fabricating
reference block lag or authoritative reporter status.
